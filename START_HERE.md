## 🚀 Cara Buka Aplikasi

### Option 1: Web (Paling Mudah)
1. Tekan `w` di terminal
2. Atau buka browser: http://localhost:8081

### Option 2: Android
1. Install Expo Go dari Play Store
2. Scan QR code di terminal
3. Atau tekan `a` di terminal

### Option 3: iOS
1. Install Expo Go dari App Store
2. Scan QR code dengan Camera app
3. Atau tekan `i` di terminal

## 🐛 Jika Ada Masalah

### Chart tidak muncul
1. Wait 5-10 seconds (TradingView loading)
2. Check internet connection
3. Try different asset

### Server error
1. Press Ctrl+C to stop
2. Run: `cmd /c "npm start"`

### Want to restart
1. Press `r` in terminal to reload
2. Or press Ctrl+C and run `cmd /c "npm start"` again
